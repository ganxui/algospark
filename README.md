# AlgoSpark

AlgoSpark — учебное веб-приложение для изучения циклов `for` в Python. Курс рассчитан на подростков 12–17 лет и включает 12 уроков с теорией и практическими заданиями.

[finplus.su/algospark](https://finplus.su/algospark/) - готовая сборка.
[Видео](https://ya.disk.com/) - видео презентация.
## Возможности

- Последовательное обучение: каждый урок содержит теоретический блок, пример и три задания.
- 36 заданий пяти типов: выбор ответа, восстановление порядка строк, заполнение пропуска, поиск ошибки и написание программы.
- Проверка решений, подсказки и повторное прохождение уроков.
- Карта курса, баллы опыта, награды и сохранение прогресса в браузере.
- ИИ-наставник Спарк для вопросов по материалу урока.
- Адаптивный интерфейс и установка приложения как PWA с офлайн-доступом после первой загрузки.
- Демонстрационный режим для просмотра всех уроков без изменения прогресса.

## Использованные технологии

| Область | Технологии | Назначение |
| --- | --- | --- |
| Интерфейс | HTML, CSS, JavaScript (ES Modules) | Экраны курса, практические задания и адаптивная вёрстка |
| Сборка | Vite 6.1, npm | Локальная разработка и сборка приложения |
| Сервер | Node.js, встроенный модуль `node:http` | API наставника и обработка запросов к провайдеру ИИ |
| ИИ-наставник | DeepSeek API | Подсказки Спарка с учётом текущего урока и попытки решения |
| Учебный редактор | Интерпретатор на JavaScript, изолированный `iframe` | Выполнение поддерживаемых конструкций Python с ограничением числа итераций |
| Хранение данных | localStorage | Сохранение прогресса и настроек в браузере |
| Установка и офлайн-доступ | PWA, Web App Manifest, Service Worker | Установка приложения и доступ к учебным материалам после первой загрузки |
| Звуковые эффекты | Web Audio API | Программный синтез звуков интерфейса |
| Тестирование | Node.js Test Runner (`node:test`) | Проверка интерпретатора и API наставника |
| Автоматические проверки | GitHub Actions | Запуск тестов и сборки при изменениях в репозитории |
| Развёртывание | nginx, systemd | Конфигурация маршрутов и запуск API как службы; примеры приведены в `deploy/` |

Python используется как язык учебных заданий. Интерпретатор написан на JavaScript и поддерживает только конструкции, необходимые для курса.

При разработке использовался Codex для помощи с кодом, документацией и проверками. Он не является зависимостью приложения; работу наставника обеспечивает DeepSeek API.

## Быстрый запуск

Требования: Node.js 22.9 или новее и npm.

```sh
git clone https://github.com/ganxui/algospark.git
cd algospark
npm ci
npm run dev
```

Приложение доступно по адресу `http://127.0.0.1:5173/algospark/`. Если порт занят, Vite укажет другой адрес в терминале. Для прохождения уроков и использования встроенных подсказок настройка ИИ не требуется.

## Проверка и сборка

```sh
npm test
npm run build
npm run preview
```

Готовая сборка сохраняется в `build/`. Команда `npm run preview` запускает её локальный просмотр, по умолчанию — `http://127.0.0.1:4173/algospark/`.

Тесты проверяют учебный интерпретатор и API наставника. Внешний API заменён локальной заглушкой: ключ провайдера и платные запросы не используются.

## Настройка ИИ-наставника

Спарк работает через DeepSeek API. Для подключения необходимы доступ к интернету и API-ключ; модель по умолчанию — `deepseek-flash`.

1. Скопируйте `api/.env.example` в `api/.env.local`.
2. Укажите ключ в переменной `ALGOSPARK_DEEPSEEK_API_KEY`.
3. В отдельном терминале выполните `npm run start:api`.
4. Запустите приложение командой `npm run dev`, если оно ещё не запущено.

Vite перенаправляет запросы `/api/algospark/chat` на локальный сервер `127.0.0.1:3101`. Параметры модели, порта и общего суточного лимита приведены в [`api/.env.example`](api/.env.example).

Наставник объясняет материал и даёт наводящие подсказки по текущему заданию. Для одного задания доступны 10 успешных ответов за 24 часа. Общий лимит по умолчанию — 3600 ответов в сутки; ошибки провайдера не учитываются. Счётчики хранятся в памяти сервера и сбрасываются при перезапуске.

### Обработка данных

Внешнему провайдеру передаются вопрос, контекст задания, текущая попытка решения и краткая история диалога. Сервер маскирует распространённые форматы персональных данных и ключей перед отправкой, но это не заменяет проверку сообщения пользователем. Не вводите в чат конфиденциальные данные.

История чата хранится в памяти страницы. Прогресс и случайный идентификатор браузера сохраняются локально; идентификатор используется для учёта запросов.

Файл `api/.env.local` исключён из Git. API-ключи и другие секреты должны храниться вне репозитория.

## Структура проекта

```text
src/app.js                логика уроков, проверка решений и учёт прогресса
src/curriculum.js         содержание курса и задания
src/core/                 учебный интерпретатор, звук и локальное хранилище
src/services/ai-chat.js    клиент ИИ-наставника
src/styles/               стили интерфейса
public/                   статические ресурсы и файлы PWA
api/server.mjs            HTTP API наставника
tests/                    тесты интерпретатора и API
deploy/                   примеры конфигурации сервера
```

Учебный интерпретатор поддерживает подмножество Python, необходимое для выполнения заданий, и не заменяет полноценную среду Python. Код выполняется в изолированном iframe с ограничением числа итераций.

## Развёртывание

После `npm run build` разместите содержимое `build/` по маршруту `/algospark/`. Этот префикс используется для загрузки ресурсов, PWA-манифеста и Service Worker.

Для работы наставника запустите API отдельным процессом и настройте перенаправление `/api/algospark/chat` на его локальный порт. В каталоге [`deploy/`](deploy/) приведены примеры конфигурации systemd, nginx и переменных окружения. Перед использованием укажите пути, пользователя службы и параметры своего сервера.
