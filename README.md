# AlgoSpark

Мобильное учебное веб-приложение для подростков 12–17 лет. Тема модуля — **циклы `for` в Python**: от повторения команды до алгоритма маршрута дрона.

**Рабочая версия: [finplus.su/algospark/](https://finplus.su/algospark/).** Регистрация не требуется.

## Возможности

- 12 последовательных уроков, каждый с короткой теорией, примером и тремя заданиями.
- 36 заданий пяти форматов: выбор ответа, порядок строк, заполнение пропуска, поиск ошибки и ввод короткой программы.
- Проверка ответа, повторные попытки и подсказки.
- Карта, XP, открытие следующих уроков и итоговый значок.
- Экран результата после первых трёх уроков с продолжением маршрута; итог всего модуля после двенадцатого.
- Повторное прохождение и локальное сохранение прогресса.
- Мобильный интерфейс с матовыми стеклянными блоками и закреплённой кнопкой проверки.
- PWA, офлайн-доступ после первой загрузки и необязательный AI-наставник Спарк.
- Демо-режим открывает все уроки, не изменяя учебный прогресс и награды.

## Быстрый запуск

Нужны Node.js 22.9 или новее и npm. Проект работает самостоятельно и не требует исходников основного FinPlus.

```sh
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite, с маршрутом `/algospark/` (обычно `http://127.0.0.1:5173/algospark/`). Уроки и встроенные подсказки доступны без настройки AI.

## Проверка и сборка

```sh
npm test
npm run build
npm run preview
```

Сборка находится в `build/`. Preview обычно доступен по адресу `http://127.0.0.1:4173/algospark/`. Тесты API используют локальную заглушку и не требуют настоящего ключа или обращения к платному провайдеру.

## AI-наставник Спарк

Используется DeepSeek API; модель по умолчанию — `deepseek-flash`. Для чата нужен интернет и собственный ключ провайдера. Ключ не нужен для прохождения курса.

1. Скопируйте `api/.env.example` в `api/.env.local`.
2. Заполните `ALGOSPARK_DEEPSEEK_API_KEY` локально.
3. В отдельном терминале выполните `npm run start:api`.
4. Оставьте Vite запущенным: он перенаправляет `/api/algospark/chat` на локальный API `127.0.0.1:3101`.

Браузер передаёт вопрос, контекст урока и задания, текущую попытку, короткую историю диалога и случайный идентификатор браузера. Имя, почта и телефон не запрашиваются. История диалога хранится в памяти страницы; прогресс и анонимный идентификатор — локально в браузере.

Для каждого задания доступны 10 успешных вопросов за 24 часа. Следующее задание имеет собственный лимит; ошибки провайдера не расходуют вопросы. Общий серверный лимит по умолчанию — 3600 успешных ответов в сутки. Счётчики хранятся в памяти API и сбрасываются при его перезапуске.

Спарк помогает по текущей теме, возвращает посторонние вопросы к программированию и по системным правилам не должен выдавать готовые решения. Сервер дополнительно фильтрует ответы, похожие на код, и маскирует распространённые форматы персональных данных и ключей.

**Не публикуйте `api/.env.local`, действующие API-ключи, SSH-ключи и серверные настройки.** В репозитории есть только пустые примеры окружения.

## Технологии и структура

HTML, CSS, JavaScript modules, Vite, Node.js HTTP API, Service Worker, localStorage, Web Audio API.

```text
src/app.js                 логика уроков, проверки, прогресс и награды
src/curriculum.js          исходные 12 уроков и 36 заданий
src/core/                 запуск учебного кода, звук и локальное хранилище
src/services/ai-chat.js    клиент AI-наставника
src/styles/               оформление и адаптивные стили
public/                   PWA-манифест, иконка и Service Worker
api/server.mjs            отдельный API Спарка
tests/                    тесты учебного редактора и API
deploy/                   примеры systemd/nginx и окружения
```

Редактор поддерживает ограниченное учебное подмножество Python, необходимое для заданий; это не полноценная установка Python. Код выполняется в изолированном iframe с ограничением числа повторов.

Звуковые эффекты программно синтезируются через Web Audio API. Внешние аудиозаписи не используются.

## Развёртывание

Разместите содержимое `build/` по маршруту `/algospark/`. Сохраните этот префикс для ресурсов, PWA-манифеста и Service Worker. Для чата отдельно запустите API и перенаправьте `/api/algospark/chat` на его локальный порт.

`deploy/algospark-ai.service` и `deploy/algospark-ai-nginx.conf` — примеры для адаптации под свой сервер; реальные конфигурации и ключи сюда не включены. Репозиторий не содержит исходников, базы или пользовательских данных основного FinPlus.
